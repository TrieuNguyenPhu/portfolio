# Product

## Purpose

Present Nguyen Phu Trieu as an early-career Cloud DevOps and DevSecOps engineer through concrete project and professional evidence, while opening with a memorable authored Three.js experience.

## Audience

Recruiters, hiring managers, platform engineers, and security engineers evaluating Cloud DevOps, DevSecOps, or Infrastructure Security candidates.

## Information architecture

- The root route is the exact ThreeUI Working Volumes shelf.
- A persistent portfolio bar exposes the résumé and profile without modifying the authored frame.
- The profile maps the supplied CV into seven volumes: SecKube, Foresight-Lens, ShortenLink, XBrain, Techhaus Vietnam, Systems Toolkit, and UIT & Beyond.
- Contact, GitHub, LinkedIn, live project, and repository links remain direct.

## Evidence boundaries

Only information present in the supplied CV or existing verified project links is used. No client work, testimonials, commercial metrics, certifications, or seniority claims are invented.

## Technical constraints

- Next.js 16 App Router and React 19.
- `@designcodeio/threeui@1.1.0` with Three.js `0.165.0`.
- Exact registered source files and asset paths.
- Same-origin frame access for the package customization layer.
- Static production routes deployed to Vercel.
- Responsive, keyboard accessible, reduced-motion aware, and readable without WebGL.
